# 구미공실 quick 운영원칙

- active quick은 공개 후보로 관리하되 주소, 호실, 종류, 보증금, 월세, 관리비와 법정 표시정보(면적, 층, 방향, 주차, 입주일, 사용승인일, 표시정보)가 모두 확인된 경우에만 공개한다.
- 사진이 없으면 `사진 준비중`을 표시한다.
- 사진이 한 장이라도 추가되면 즉시 그 사진을 사용한다.
- 현장 확인 정보는 동일한 `properties.id`에 순차적으로 보충한다.
- 사진과 면적, 층, 방향, 주차, 입주일이 갖춰지면 `normal`로 승격한다.
- quick과 normal을 별도 행으로 동시에 만들지 않는다.
- 전체 batch 완료 시 원본에서 사라진 quick만 `missing`으로 바꾸고 비노출한다.
- chunk 업로드 도중에는 missing 처리를 하지 않는다.
